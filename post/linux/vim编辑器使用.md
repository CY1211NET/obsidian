## 1. 核心模式切换

这是初学者最容易困惑的地方。记住：**永远先按 `Esc` 回到普通模式。**

- **`i`**: 进入插入模式（在当前光标前开始输入）。
    
- **`Esc`**: 退出当前模式，回到**普通模式**。
    
- **`:`**: 在普通模式下输入，进入**底行命令模式**。
    

---

## 2. 文件的保存与退出（底行模式）

在普通模式下输入 `:` 后紧跟以下字母：

- **`:w`**: 保存（write）。
    
- **`:q`**: 退出（quit）。
    
- **`:wq`**: **保存并退出**。
    
- **`:q!`**: **强制退出**，不保存修改。
    
- **`:x`**: 保存并退出（同 `:wq`，但仅在内容有变动时才写入）。
    

---

## 3. 光标快速移动（普通模式）

除了方向键，熟练工更爱用这些：

- **`h` `j` `k` `l`**: 左、下、上、右。
    
- **`w`**: 跳到下一个单词开头。
    
- **`0`**: 跳到**行首**。
    
- **`$`**: 跳到**行尾**。
    
- **`gg`**: 跳到**文件开头**。
    
- **`G`**: 跳到**文件末尾**。
    
- **`数字 + G`**: 直接跳到指定行（例如 `10G` 跳到第 10 行）。
    

---

## 4. 编辑与删除（普通模式）

- **`x`**: 删除光标所在的单个字符。
    
- **`dd`**: **删除（剪切）当前行**。
    
- **`数字 + dd`**: 删除多行（如 `3dd` 删除当前及下两行）。
    
- **`yy`**: **复制**当前行。
    
- **`p`**: 在光标后**粘贴**。
    
- **`u`**: **撤销**上一步操作（Undo）。
    
- **`Ctrl + r`**: **反撤销**（Redo）。
    

---

## 5. 搜索与替换（底行模式）

- **`/关键字`**: 向下搜索。按 `n` 跳到下一个，`N` 跳到上一个。
    
- **`?关键字`**: 向上搜索。
    
- **`:%s/旧内容/新内容/g`**: 全文替换（`g` 表示全局替换）。
    

---

## 6. 高级小技巧

|**命令**|**作用**|
|---|---|
|**`set nu`**|显示行号（底行模式输入）|
|**`v`**|进入**可视模式**（用于鼠标感划选文本）|
|**`.`**|**重复**上一次的编辑操作（神技，省去重复输入）|
|**`o`**|在当前行下方新建一行并进入插入模式|

## 7.Recover解决
在 Vim 中看到 **"Found a swap file"** 或 **"Recovery completed"** 这样的提示，通常是因为 Vim 意外退出（比如 SSH 断开、终端关了、系统死机）而产生了一个 `.swp`（交换文件）。

这是 Vim 的一种保护机制，防止你丢失未保存的工作。

---

### 1. 为什么会出现这个界面？

当你编辑 `file.txt` 时，Vim 会自动创建一个隐藏的 `.file.txt.swp` 文件。

- **正常退出：** Vim 会自动删掉这个 `.swp`。
    
- **异常退出：** `.swp` 依然残留在硬盘上。当你再次打开该文件时，Vim 发现有“存货”，就会弹出 Recover 提示。
    

---

### 2. 面对 Recover 提示该选哪个？

当你看到 `[O]pen Read-Only, (E)dit anyway, (R)ecover, (D)elete it, (Q)uit, (A)bort` 时：

1. **如果你想找回没保存的数据：**
    
    - 按 **`R` (Recover)**：进入文件。
        
    - 检查内容无误后，输入 `:wq` 保存退出。
        
    - **关键步骤：** 退出后，你需要手动删除掉那个交换文件，否则下次打开还会报错。
        
2. **如果你确定不需要旧数据（或者内容已经是新的）：**
    
    - 按 **`D` (Delete it)**：直接删除交换文件并进入编辑。这是最省事的做法。
        
3. **如果你不确定：**
    
    - 按 **`Q` (Quit)**：先退出，去备份一下原文件再回来看。
        

---

### 3. 彻底解决“阴魂不散”的 Recover 提示

如果你已经 `Recover` 并保存了文件，但每次打开还是提示，说明 `.swp` 隐藏文件还在。

**手动删除方法（以 `test.txt` 为例）：**

在 Linux 终端执行：



```bash
# 查看隐藏的交换文件
ls -a
# 删除它（交换文件通常以 . 开头并以 .swp 结尾）
rm .test.txt.swp
```

---

## 4. 预防与优化技巧

如果你觉得 `.swp` 文件在当前目录下很乱，可以在你的 `~/.vimrc` 配置文件中加入以下设置，把所有的交换文件统一管理：



```bash
" 在家目录下创建一个专门存放交换文件的文件夹
mkdir -p ~/.vim/swap

" 修改 .vimrc
set directory=$HOME/.vim/swap//
```

**你现在是正卡在 Recover 界面不知道怎么退出来，还是想知道如何批量清理这些交换文件？**
